# 大库维护与任务交互

本文记录第一批、第二批改进的使用方式与接口变化。功能已经本地验证，尚未部署生产；没有以生产 40 万影片进行耗时或容量测试。

## 任务与请求反馈

- 任务列表每页 50 条，可按名称或 ID 检索；详情通过独立接口读取，历史任务链接不受当前列表页限制。
- 子任务每页 100 条，可按影片目标或子任务 ID 搜索。任务区分排队、执行、等待重试、暂停调度、部分失败及后续处理。
- 任务详情汇总实际子任务结果，清退设置完成后提供后续删源任务链接。父任务完成设置不代表所有影片已经清退。
- 数据读取失败显示错误与重试入口，不再当作空列表。提交期间显示状态并防止同一入口重复点击；成功提示可以直接打开任务。
- 页面暂停的是调度：已经开始的步骤需要收尾。取消、重试和删除仍通过任务详情操作。

## 任务详情中的统一预览

- 输出库变更、站点清退、批量操作和同片整理：继续显示原影响预览；执行任务提供原预览链接，能查看当时确认的范围。
- 媒体库维护的清理、无可用源归档及恢复：任务详情内直接显示原清单与确认入口，同时保留维护页入口。
- 输出库「清理残留目录」：手动操作先生成只读检查任务。任务详情分页展示完整目录清单，不再仅依赖最多 200 条日志；确认后只处理原清单，根目录、挂载、回收保留天数或文件变化会拒绝或跳过，不把新出现的残留加入原范围。定时清理仍按原计划自动执行，并保存结果。
- 目录占用与图片清理：从任务详情按具体任务编号读取统计和完整图片清单，不会替换成该库最新扫描；清理任务可返回原预览。
- STRM 改前缀及回滚：任务详情分页展示实际记录的文件、修改前后内容及回滚状态。

关闭弹窗不会停止后台任务，刷新或从任务列表重新打开可继续查看。旧残留检查如果当时只写日志、没有保存清单，会明确提示无法还原，需重新执行只检查；不会根据当前磁盘内容伪造历史预览。配置导入和执行时间计算仍是同步预览，不额外改成后台任务。

## 设置保存与输出同步

修改对外地址、播放模式、令牌、路径模板、输出根目录或 NFO 开关后，配置立即保存，已有输出需要重写。设置页显示持久化同步状态，离开页面、刷新和服务重启不会丢失提醒。

只有绑定同一配置版本的全库重写成功，才标记为已同步；取消、暂停、部分失败或仅重写单库均不能消除提醒。重写期间再次修改配置会生成新版本，旧任务不能覆盖新状态。保存失败保留输入草稿，保存期间禁止继续改字段，后台状态轮询不覆盖未保存的草稿。

## 先预览再变更

输出库的规则、来源、排除、目录、外部整理目录或版本设置发生变化时，先创建后台影响预览；涉及归库的新库也使用该流程。仅新建空库或改名称仍直接保存。

预览只读取本地数据库，不抓详情、不逐片测试播放，不改配置、归属或文件。页面列出预计加入、移出、重写、归档的数量，最多 30 个样本、归库原因及配置前后差异。数量中的加入/移出/重写是输出归属数，一部影片涉及多个库时会计入多次；匹配影片是作品数。

预览属于普通任务，可取消、从历史详情继续查看及确认。离开页面不取消任务；修改预览请求需要重新计算。计算按每批 200 部读取，按开始时的 ID 上界限定本次扫描。

确认后，后台先重新核对范围再执行。库或清退范围已变化时，尚未执行的操作会停止并要求重新预览；相关配置不在第一次范围校验失败时保存。库变更逐片复核条件，文件副作用完成后推进游标。普通文件变更与确认执行互斥，播放读取不使用这把锁；正在进行的写入需要先收尾。

库变更已经保存配置但只处理一部分时，库保留“未完成变更”状态，普通规则归库、归并及写出不会绕过确认继续修改它。可在任务详情重试；条件发生变化时，在库表单重新预览剩余范围，新确认任务接管后继续处理。已经完成的部分保留，不自动回滚。

有排除库的新增归属仍等待原有订阅确认机制再写出 STRM。依赖的来源库也按现有归并策略推进，不绕过等待条件。实际文件位置、共享目录、挂载状态由原有文件处理逻辑核对；外部整理目录的变化只同步位置，不搬动或覆盖 MDCNG 的 NFO、图片。移出/删源仍沿用现有回收与归档语义。

## 清退与恢复

站点清退也先预览。可保留的替代源只按站点启用、线路启用和支持策略判断，页面说明这些源尚未逐片验证播放。

确认执行会停用该站及其启用订阅，取消该站排队中的抓取，并为冻结的影片范围创建删源任务；无可用替代源的影片按原有逻辑移出输出并归档。清退设置与子任务回执持久化保存，设置保存中断后重试继续同一个删源任务。每部删源前会再检查条件，有变化则停止处理该影片。

恢复使用清退记录与原有归档逻辑，保留清退任务以便找回源和当时停用的订阅。清退任务正在运行或暂停时，需要先完成或取消，再执行恢复。清退设置未完成时先重试父任务；不要单独恢复其尚未启动的删源子任务来代替设置步骤。

## 跨页与筛选批量

- “选中本页”只增减当前页；翻页或换排序保留跨页选择，改变筛选清空选择。
- “跨页已选”与“当前筛选全部”明确区分。按筛选全部支持查找其他源、刷新详情、加入输出库；移出、删源和恢复源需要显式选择影片。
- 服务端计算并保存实际匹配范围，展示显式选择、实际匹配、已存在及不适用数量。没有待处理影片时页面不再提交空执行任务。
- 确认按筛选结果处理后，新入库影片不会加入本次目标。后台按快照分批生成子任务，队列插入与游标同事务保存，重启后不遗漏或重复入队。
- 显式跨页选择使用同一预览流程，不再受旧批量接口 500 个 ID 的限制。补源、刷新详情在执行阶段仍会访问源站，沿用站点限速、并发和重试设置。

## API 与升级兼容

启动时执行一次 SQLite v19 迁移：新增子任务结果列、输出库变更状态列，以及预览快照和提交回执表。不重建影片数据，也不批量探测源站。上线前按现有运维流程备份数据库与媒体记录；旧版本程序不理解新的任务类型，不应在这些任务未完成时交替运行新旧服务。

| 接口 | 行为 |
|---|---|
| `GET /api/jobs` | 默认保留数组；`paged=true` 返回 `{items,total}`，支持 `limit/offset/q` |
| `GET /api/jobs/{id}` | 独立任务详情、阶段及实际结果摘要 |
| `GET /api/jobs/{id}/tasks` | 默认保留数组；`paged=true` 返回分页，`q` 检索目标或 ID |
| `POST /api/operations/preview` | 202，返回 `{job_id}`，后台计算 |
| `GET /api/operations/{id}` | 返回 `{job,preview,preview_token}`；完成后预览和确认令牌才可用 |
| `POST /api/operations/{id}/apply` | body `{preview_token}`；202，返回执行 `{job_id}`；重复确认返回同一个任务 |
| `POST /api/sites/{site}/retirement/preview` | 改为异步 202 `{job_id}`，不再同步返回统计 |
| `POST /api/sites/{site}/retirement` | 要求 `{preview_id,preview_token}`，缺少或站点不匹配返回 409 |
| `POST /api/libraries`、`PUT /api/libraries/{id}` | 范围变更需匹配的 `preview_id/preview_token`；缺少或配置不匹配返回 409；空库创建/纯名称变更仍可直接调用 |

示例：按筛选结果加入输出库，筛选与影片列表使用相同条件；`library_id` 换成实际目标库 ID。

```json
{
  "kind": "selection",
  "payload": {
    "action": "add",
    "library_id": 2,
    "query": {"model": ["m1"], "filter": "active"}
  }
}
```

库预览使用 `{kind:"library",payload:{library_id,values}}`；新库省略 `library_id`，`values` 是库表单字段。清退预览使用 `{kind:"retirement",payload:{site:"jable"}}`。

`POST /api/jobs` 与通用预览创建支持 `Idempotency-Key`（最多 128 个字符）。相同键、相同请求返回原任务；同一键换内容返回 409；有意重新创建使用新键。网页合并同时发生的相同 POST，网络错误或服务端错误后的重试保留键。确认令牌绑定已保存的预览，修改配置或目标后需要重新预览。

快照空间随匹配/受影响数量增长，任务历史需要按需清理。先删除关联执行任务，再删除预览，快照随预览删除；清退任务在恢复清退前受保护，仍有未完成库变更的执行任务不能删除。单纯取消任务不会释放其快照，便于追踪与恢复。内部范围及设置上下文不通过任务 API 公开。

## 本地验证

- Python 完整回归：232 passed、2 skipped；新增 15 个工作流测试，覆盖确认匹配、防重、范围改变、620 部显式选择、入队断点、清退设置中断、并发设置保存及外部整理文件保护。
- 前端 TypeScript 检查及生产构建通过。
- Edge 无头浏览器使用独立临时库与模拟抓取器完成 7 个流程：历史任务/深页子任务查找、跨页 100 部预览并加入、同步提醒跨导航刷新和取消保留、保存失败保留草稿、规则预览不提前保存并归入 61 部、读取失败重试、390px 深色布局。没有页面脚本错误，并目视检查截图。
- 这些验证不代表生产迁移、真实挂载/外部整理器并发、源站播放或 40 万库的性能验收。
