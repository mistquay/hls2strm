# 外部刮削兜底：手动源站资料补全

入口：**输出库与订阅 → 外部库菜单 → 源站资料兜底补全**，或 **媒体库维护 → 源站资料补全**。

仅手动运行，不增加定时任务；可以隔一段时间按需检查。外部刮削器继续作为主要资料来源，常规订阅、重写、同步位置仍不改写外部库的 NFO 或图片。

## 三个独立模式

| 模式 | 范围 | 行为 |
| --- | --- | --- |
| 补缺失 NFO / 图片 | 所选库的外部整理目录 | 缺 NFO 时生成；可选下载缺失海报和背景图。已有 NFO 不改，已有图片不覆盖。 |
| 已有 NFO 补空字段 | 所选库中已有有效 NFO 的影片 | 只填空字段，保留已有标题、演员、评分、扩展节点及注释。不补图片、不搬文件；没有 NFO 的提示改用第一种模式。 |
| 接管未整理文件 | 所选库收件目录，加上用户明确指定的可选失败目录 | 唯一识别影片并确认本库输出关联后，将独立影片目录的 STRM 和已有资源迁往 `外部目录/_hls补全/{slug}/`，保留原文件名，补足能够补足的资料，更新输出路径。 |

接管不会更改库归属，不按番号把不同版本合并。外部目录已有同一影片、目标目录已经存在、共享目录、未知文件、实体影片或链接均跳过，不合并覆盖。第一版接管要求一片一个目录；平铺在失败根目录或共享目录中的文件需先整理为独立目录。没有本库输出关联的文件不自动纳管。

失败目录必须是服务端可见的绝对路径，明确属于所选库，且不与任何库、归档或服务数据目录重叠。不会读取 MDCNG 的任务状态，**文件留在收件目录不等于刮削失败**。接管前应自行确认它确实不再由外部刮削器处理。

## 操作顺序

1. 选择一个外部库和一个模式；需要时填写独立失败目录。图片选项只作用于第一、第三种模式。
2. 点击“只读检查并生成本模式预览”。检查本身不联网下载图片、不改媒体文件，任务会保存完整分页清单。
3. 展开条目查看原路径、目标路径、字段差异、文件动作、缺失信息与跳过原因。改动表单后重新预览，历史任务范围保持不变。
4. 暂停该库对应的外部刮削写入，勾选确认，再确认执行。确认作用于预览全部可处理条目，不限当前页。
5. 从补全历史或任务详情查看结果；支持暂停、恢复、取消及重试未完成项。关闭页面不停止任务，取消不撤销已经完成的文件操作。
6. 补全修改后重新运行“扫描磁盘与 NFO”，发布新的本地维护资料。Emby/Jellyfin 的更新取决于它自己的媒体库扫描设置，本功能不调用刷新 API。

外部目录不存在、权限失败或身份改变时不接管。外部目录没有可识别 STRM 时默认阻止接管；确认挂载正常、确实要初始化空目录后，才勾选“允许接管到空外部目录”。这个选项不会自动创建失联的外部根目录。

## 资料规则

- 使用数据库当前已保存的源站资料，预览冻结本次补丁；第一版不自动联网补抓详情，不调用 MDCNG API。
- 支持标题、原始标题、番号、厂商、导演、系列、演员、类型、标签、时长。列表字段整体为空才补，不向已有演员/类型列表混入源站值。
- 新建 NFO 需要有效标题，只有番号时提示资料不足；未知资料留空，不宣称完整刮削成功。
- 历史 `release_date` 缺少可信的逐字段来源，部分站点曾使用上架日期回退，因此暂不向 NFO 补发行日期或年份。已有 NFO 日期保留。
- 不编造剧情、评分，不把标题写成剧情。数据库只能标为合并后的源站资料，不能冒称每个字段都能追溯到某一站点。
- 图片优先使用 `cover_url`，没有时降级用 `thumb_url` 并提示；确认执行后下载、验证和转换为 JPEG。图片不自动裁剪，宽图不能保证是 DVD 封套，也不能保证降级图片有高质量海报效果。
- 同目录已存在相应类型图片就不新增另一份；遵守现有资源禁补和停止收录规则，失效或被禁用的源不用于接管。
- 有效 NFO 按安全 XML 解析后增补，不重建整份元数据。文件格式会统一为 UTF-8；原 XML 的空白、声明格式可能变化，但原有字段、扩展节点、注释保留。损坏、日期冲突、番号/版本不符或多份 NFO 无法确定时跳过。

## 写入、重试和备份

执行前复核根目录身份、影片归属、禁补规则、输出关联和预览文件证据。源目录变化时跳过，不扩大已确认范围。外部工具不受本服务内部文件锁约束，因此执行及重试时必须保持对应刮削暂停。

图片与文件先准备完毕，再开始发布，STRM 最后发布。接管按文件复制、校验后移除原文件，支持跨盘；中断时可能暂时保留两端，**应重试同一执行任务**，不要重新创建接管任务或手工删除其中一端。源目录可能留下空目录，不递归删除。两端出现非本任务内容时停止该条目并保留现场。

写入凭据保存在现有任务及维护条目表，不增加数据库版本。准备文件放在服务数据目录 `metadata-fallback/<条目 ID>/`；成功后释放本次准备副本，修改过的原 NFO 保留为 `original.nfo`。未完成任务的准备文件应保留供重试，不能随意清理；当前不提供一键回滚或自动过期备份。执行任务及被引用的预览记录暂不允许删除。

新文件发布使用不覆盖已有目标的方式；Windows 使用同目录重命名，POSIX 使用同目录硬链接。目标文件系统不支持所需操作时条目失败并保留源文件，不退回有覆盖风险的写法。网络挂载需先用少量文件验证。

## 验证边界

本地临时目录覆盖三个模式、已有 XML 保留、禁收/禁补、挂载确认、文件变化、失败目录、重复副本、执行确认、暂停/重试接口及接管中断恢复。浏览器使用模拟库检查桌面和手机布局、三种模式预览以及缺 NFO 的确认执行。

未对真实 MDCNG 目录、真实下载站点、远程挂载或媒体服务器进行验收；首次使用建议先选小库并核对预览。
