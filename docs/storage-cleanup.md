# 磁盘删除、目录统计与额外剧照清理

当前统一入口和扩展功能见 [媒体库维护使用说明](library-maintenance.md)。本文保留最初的额外剧照清理行为记录；旧任务处理接口继续兼容。

## 整部影片从磁盘删除以后

磁盘删除不会自动删除影片、来源或输出库的数据库记录，也不会使影片自动停止跟踪。

- 外部整理库的「同步位置」按 STRM 内容扫描收件目录和整理目录，找不到时统计为缺失；不会因缺失删除记录或补写整部影片。
- 订阅/列表抓取再次遇到该影片，或执行「核对并补回」，会尝试找回或补回 STRM。`external_restore`（设置 → 外部整理与归档 → 外部整理库补回丢失的 strm）默认开启。真正找不到且外部整理目录可用时，写回收件目录，外部刮削器可能再次处理它。
- 外部整理目录不存在或没有可用 STRM 时，默认不补回，以免挂载异常导致全库重新刮削；手动核对的强制补回选项可以覆盖这一保护和 `external_restore` 开关。
- 普通输出库会在核对修复或抓取再次遇到影片时补写其管理的输出。
- 「重写输出」对已记录但丢失的外部 STRM 不会直接补写；磁盘上的删除也不等同于删除在线播放源。

以上是 hls2strm 的行为；MDCNG 是否重新下载图片取决于它的刮削配置。关闭 `external_restore` 可以避免常规补回，但不会清除已有记录，也不是停止跟踪功能。

## 使用清理功能

输出库 → 更多操作 → **目录占用与图片清理**。

有外部整理目录时扫描该目录，否则扫描输出库目录。输入每个 `extrafanart` 保留的图片数（默认 3，填 0 表示全部清理），点击「扫描并预览」。按文件名自然顺序保留，例如 `fanart1.jpg`、`fanart2.jpg` 排在 `fanart10.jpg` 前面。

扫描显示总文件大小、额外剧照、其他图片、NFO/STRM、其他文件，以及一级子目录占用和可清理空间。只统计普通文件，不跟随符号链接、Windows junction，不进入 `.hls2strm-trash`。大小按文件逻辑长度累计，硬链接、压缩、稀疏文件或快照等会影响磁盘实际回收量。

确认后永久删除预览清单中的额外图片，不经过回收区。仅处理名称为 `extrafanart` 的目录直接包含的图片文件，保留其他类型、嵌套子目录、影片目录、主封面、STRM 和 NFO。不会删除数据库影片记录。

操作前暂停外部刮削/整理写入。执行时核对根目录、父目录及图片身份、长度和修改时间；跳过消失、替换或已变化的文件，新出现的图片不纳入本次范围。单个文件删除失败会记录并继续处理其他文件。应用内的文件变更在批次期间互斥；外部进程不受该锁控制。

扫描和清理在任务队列执行，支持在任务页暂停、恢复、取消。扫描中断后从头重新统计；清理按持久化批次游标继续，进程异常退出后已消失的图片会被跳过，统计可能少计异常退出前尚未记账的一批。关闭弹窗不会取消任务，重新打开可查看最近一次扫描及清理结果。清理后重新扫描以刷新占用。

清理清单在数据目录 `storage-plans/` 中，按扫描任务编号保存，不写入媒体目录；删除对应扫描任务时一并删除清单（有清理任务引用时需先删除清理任务）。统计和删除只访问本地文件系统，不调用外部网站或 MDCNG API。MDCNG 后续重刮仍可能重新下载额外剧照；要长期限制占用，还需在刮削工具中关闭或限制额外剧照下载。
