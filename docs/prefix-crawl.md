# 按前缀批量抓取（第一期）

从影片库当前筛选、显式跨页选择或全库统计番号前缀，再选择支持搜索的目标站点执行一次性批量抓取。支持补源并扩库、仅给统计快照内影片补源；不增加前缀集合订阅。

统计范围冻结为影片 ID 快照。站内模糊搜索与本地番号前缀核验分开；默认严格核验。已有影片维持输出库归属，新片加入选择的输出库并遵守排除规则。首次完整扫描，不使用连续已知影片提前停止；可设置每个前缀页数上限。

## 使用方式

1. 在影片库筛选“有 JAVMost 源”“只有一个源”“缺少 MissAV 源”，点击“统计前缀并批量抓取”。
2. 选择当前筛选的全部影片、显式勾选影片或整个影片库，点击“统计前缀”。统计覆盖全部匹配影片，不受影片列表分页限制。
3. 搜索、排序并勾选前缀，或全选搜索匹配的前缀；可手工补充和复制已选前缀。`259LUXU` 与 `LUXU`、FC2 的不同写法由后端归一并去重。
4. 选择启用的目标源，可同时勾选其他目标源。覆盖数量只显示主目标源，切换主目标源沿用同一范围快照。
5. 选择“补源并扩库”或“仅给快照内影片补源”；扩库时指定新片输出库。页数为 0 表示完整扫描。
6. 创建后进入任务详情，按站点和前缀查看进度。支持批次暂停/恢复/取消、失败项重试和取消单个站点前缀。取消项不会因重试而恢复，已保存影片、源和输出保留。

日期型厂牌和无法可靠识别的番号只统计为未识别，不从标题猜系列。关闭前缀核验后，搜索结果中其他系列也可能按所选模式收录。FC2 搜索使用 `FC2` 关键词，核验仍使用规范化系列 `FC2PPV`。

## 实现与验证

- SQLite v25 增加统计快照、前缀计划及幂等结果表；原影片和源数据不迁移、不修改身份规则。快照在数据库中聚合，不向浏览器传全部影片；未被任务引用的统计快照超过一天后在下次统计时清理。
- 六个现有适配器声明关键词列表能力；前缀任务沿用站点分页、默认排序、Jable 异步块标识、限速和并发。
- 一个批次包含每个站点前缀的独立分页及详情子任务。影片和新增源计数在入库事务中记录，跨页和重试不会重复累加；同一范围的进行中任务避免重复创建。
- 搜索列表 404、解析异常或无法确认的空页记录为失败，不记为完整扫描，也不写逐片补源负缓存。列表抓完、达到页数上限、部分失败和取消分别展示。
- 本地全量回归 505 项通过、2 项跳过；后续增加的创建中断恢复、异常空页及多目标源去重测试通过，功能专项共 33 项通过。前端类型检查和生产构建通过。
- 隔离数据库真实浏览器验证：跨页筛选统计、补源并扩库、详情处理、仅补源不收新片、失败重试、全库范围、手工别名去重、暂停恢复、单前缀取消、页数上限，以及桌面和 390px 窄屏显示。测试使用样本源站页面，线上站点连通性和实际播放未验证。

接口：`POST /api/prefixes/stats`、`POST /api/prefixes/jobs`、`POST /api/prefixes/jobs/{job_id}/cancel`。批次详情及暂停、恢复、取消、失败重试沿用任务接口。接口统一认证，创建任务支持现有 `Idempotency-Key` 回执机制。
